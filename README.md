# WeatherSim 

### Virtual Weather Station Simulation using Proteus

WeatherSim is a Proteus-based weather station simulation designed to
demonstrate the measurement and monitoring of environmental parameters
using simulated sensors and embedded-system components.

The project provides a virtual environment for testing sensor
interfaces, embedded firmware, data processing, and display output
before implementing the system on physical hardware.

## Features

- Weather station simulation in Proteus
- Temperature monitoring
- Humidity monitoring
- Atmospheric pressure monitoring
- Sensor interfacing
- Embedded-system simulation
- Real-time parameter display
- Firmware testing before hardware implementation
